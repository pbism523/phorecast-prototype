# Phorecast Modern Website Prototype

This is a modern, responsive website prototype for Phorecast - a strategy consulting firm.

## Live Demo

**View the prototype here:**
https://pbism523.github.io/phorecast-prototype/

## Features

- Modern, clean design with smooth animations
- Fully responsive (mobile, tablet, desktop)
- Smooth scroll navigation
- Animated timeline for the process
- Social proof with testimonials
- Clear CTAs throughout
- Professional color scheme

## Sections

1. **Hero** - Strong value proposition with trust badge
2. **Problems** - Agitate common pain points
3. **Process** - 6-week timeline with animations
4. **Results** - Social proof with specific results
5. **About** - Who's behind Phorecast
6. **CTA** - Final call-to-action

## Tech Stack

- HTML5
- CSS3 (with CSS variables, flexbox, grid)
- Vanilla JavaScript (for smooth scroll and animations)
- Google Fonts (Inter)
